#  Project Overview

The **Personal Expense Data Analytics** project is designed to help users manage and analyze their personal expenses efficiently.  
The system stores expense records in a CSV file and provides analytics such as:

- Total expenses
- Category-wise spending
- Expense history tracking
- Visual representation using charts

This project is developed using **Python**, **CSV handling**, and **Matplotlib** for visualization.
